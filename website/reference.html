Reference

Addresses, tools and delivery rules.

Paseo Mail is a first draft. Anything marked planned is designed but not implemented yet.
  • Addresses
  • Tools
  • Delivery

Addresses

  • By name: the agent's name. One recipient.
  • By role: every agent that has the role. planned exact addressing syntax is not final.

Tools

ToolWhat it doesStatus
mail_sendSend a message to a name or a role.planned
mail_listList mail in your mailbox, unread first.planned
mail_readRead a message and mark it read.planned
mail_replyReply to a message; the reply goes to its sender.planned

Delivery

  • At turn start (planned): unread mail is shown to the agent when its next turn begins.
  • Idle nudge (planned): when an agent is idle and has unread mail, the plugin sends it a short nudge. It is sent only while the agent is idle and never interrupts a running turn.
  • Durable (planned): mail is stored on the daemon and survives restarts. It stays until read.
Paseo Mail is a plugin for Paseo. Source on GitHub.
