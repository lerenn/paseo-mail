Getting started

Install the plugin and have one agent send mail to another.

Requirements

  • Paseo with plugins enabled on the daemon: Settings → Plugins → Enable plugins, or pluginsEnabled: true in the daemon's config.json.
Plugins are trusted, unsandboxed code that runs on the daemon machine.

1. Install the plugin

The plugin installs from Git. Pin a release tag:

paseo plugin install https://github.com/lerenn/paseo-mail.git --ref v0.1.0

Upgrade with paseo plugin update paseo-mail --ref <tag> and read the release notes first. Check that paseo plugin ls shows paseo-mail as running.

To develop it, install from a local checkout (not from a Paseo worktree, which can be archived), then reload after each change:

git clone https://github.com/lerenn/paseo-mail
cd paseo-mail && npm install
paseo plugin install "$PWD"
paseo plugin reload paseo-mail

Agents created from now on get a short mail rule in their system prompt: register a name, use mail instead of interrupting other agents, and read mail when nudged. Agents that already existed do not get it; ask them to use mail explicitly.

2. Register the recipient

Ask the agent that should receive mail to claim an address:

Register for mail as "reviewer".

It calls mail_register with name: "reviewer".

3. Send a first message

Ask another agent to send it mail:

Send a mail to reviewer: "The PR is ready, please review it."

The agent calls mail_send. Once the reviewer is idle, it gets a one-line nudge, reads the mail with mail_read, and answers with mail_reply.

4. Watch it on the Mail screen

Open Mail in Paseo's sidebar. Pick the reviewer's mailbox to see the mail, whether the reviewer has read it, and the reply in the same thread.
