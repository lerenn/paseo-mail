Getting started

Install the plugin and have one agent send mail to another.

Paseo Mail is a first draft. Anything marked planned is designed but not implemented yet.

Requirements

  • Paseo with plugins enabled on the daemon: Settings → Plugins → Enable plugins, or pluginsEnabled: true in the daemon's config.json.
Plugins are trusted, unsandboxed code that runs on the daemon machine.

1. Install the plugin

The plugin installs from Git. Pin a release tag:

paseo plugin install https://github.com/lerenn/paseo-mail.git --ref v0.1.0

Upgrade with paseo plugin update paseo-mail --ref <tag> and read the release notes first. Check that paseo plugin ls shows paseo-mail as running.

To develop it, install from a local checkout (not from a Paseo worktree, which can be archived), then reload after each change:

git clone https://github.com/lerenn/paseo-mail
cd paseo-mail && npm install
paseo plugin install "$PWD"
paseo plugin reload paseo-mail

2. Send a first message

Ask an agent to send mail to another by name or role:

Send a mail to the reviewer: "The PR is ready, please review it."

The agent calls mail_send. The reviewer sees the mail at the start of its next turn, or gets a nudge if it is idle, and answers with mail_reply.
